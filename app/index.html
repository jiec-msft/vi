1. Enable cloud dictation

Your microphone starts locally while provider connects in the background. Audio is temporarily buffered in memory, then sent to your selected speech provider. Audio is not saved by this application. Service access depends on the selected provider and its configuration. Service access is preview-only and may be restricted.

Dictation preferences

Choose the microphone used on this computer. Test Mic enables device names.

Test this input for up to 10 seconds. No cloud connection; no audio is saved.

Speech appears in preview while recording. Stop to paste the final result once at the current caret in the original window. The floating window stays ready for the next recording. No live replacement or automatic undo is performed.

Off by default. When enabled, successful recordings replace your clipboard with the final text, including Record preview and recordings where automatic paste was skipped or failed. Partial results, failed transcriptions and recordings cancelled before copying are not copied. A clipboard write already requested from the OS cannot be cancelled or reverted. This option is separate from automatic paste.

Type an accelerator such as Ctrl+Shift+Space, then check for conflicts and save.

Service provider

Leave empty to use the provider's defaults. Only configure a service you trust.

Plugins

Enable or disable plugins here. Each plugin manages its configuration in its own folder. Local plugins are trusted code, not sandboxed; text filtering does not prevent audio upload.

2. Dictate into a text field

Focus the target field, press Ctrl+Shift+Space, speak, then press again. Cancel with Ctrl+Shift+Backspace. In push-to-talk mode, hold the shortcut and release to finish instead. Short speech segments finalize internally while recording continues; nothing is pasted until you stop.

You may type or move the caret during recording. Stop pastes at the current caret or replaces the current selection, just like ordinary Paste. Our review window returns to the background before pasting; switching to another external window skips paste without stealing focus. A paste request cannot prove the target accepted it: review the field before manually pasting again. The app cannot detect every password box. Do not use terminals, password fields, or sensitive forms. Automatic paste temporarily uses the clipboard and restores its previous supported formats; a newer user copy is not overwritten. Auto-copy intentionally keeps the final transcript in the clipboard. If you stop before provider is connected, the recorded audio is sent when the connection is ready.

This window supports the taskbar and Alt+Tab while open. Minimizing or closing hides it in the system tray; reopen it from the tray menu. Diagnostics contain only timing, byte counts and state changes, never tokens, audio or transcripts. macOS requires Microphone and Accessibility permissions. OS security settings and elevated applications can block automatic paste.
